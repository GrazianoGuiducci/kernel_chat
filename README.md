# Meta_Semantic_Kernel

`Meta_Semantic_Kernel` is the working name of this project. The name does **not** assert that a kernel already exists.

At the current stage this repository is the durable working surface where the semantic environment can evolve from real work performed by the live D-ND system. A kernel will be considered to exist only when what emerges can be integrated coherently into the ChatGPT cognitive/re-entry kernel used in this ecosystem.

## Present relation to the live system

The current system is active and is being used to generate new functions and products. Its existing surfaces are therefore not historical material to be merged here.

- `Meta_Skill` remains the live competence architecture and generation faculty.
- `KA` is used as a live competence for source/difference/discrimination, non-circular convergence and protection against contaminating the field with our own premature constructions.
- `dnd-skill-evolution-guard` remains the operational faculty for crystallising sufficiently supported reusable learning into persistent change.
- Other competences, tools and owner-native surfaces are used when the work requires them.

This repository does not replace those owners and does not need to copy their identities in order to use their capabilities.

## Continuity

For re-entry, read `CURRENT_STATE.md` first. Use `docs/BASELINE_0.1.0.md` when the genealogy and the reasoning that opened this project are needed. Consult the live owner-native repositories whenever current capability state matters.

When the understanding changes materially, preserve the movement by updating the current state and adding the next versioned resultant rather than silently rewriting the path that produced it.

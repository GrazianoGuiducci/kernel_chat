# Behavioral Evals

These cases test behavior, not vocabulary. A response does not pass because it
mentions KA, MAIOS, a schema name or the kernel itself.

The first proof set contains:

- directness on an ordinary bounded request;
- selective continuity when a missing relation changes the result;
- open-world handling of a relation outside the represented examples;
- retention of a verified current limit;
- separation of a useful possibility from authority to execute it;
- reviewed evolution that changes later behavior without burdening unrelated
  work.

Record actual host observations under `.repokernel/evidence/`. Keep model,
adapter version, source revision, latency/noise, result, invalidator and literal
classification. Definitions are not executed evidence.

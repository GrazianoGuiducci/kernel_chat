# ChatGPT Adapter

This adapter connects ChatGPT Custom Instructions to a user-owned MAIOS
Conversation Kernel repository. It does not turn ChatGPT into a persistent
agent runtime and does not imply endorsement by OpenAI.

Use:

1. Fork the repository.
2. Replace `<YOUR_GITHUB_USER>` in `CUSTOM_INSTRUCTIONS.md`.
3. Paste the complete text into ChatGPT Custom Instructions.
4. Record the installed source version in `INSTALLATION_STATE.md`.
5. Observe behavior through the eval cases; do not infer activation from
   installation alone.

Official host settings and limits may change. Recheck OpenAI documentation at
installation time.

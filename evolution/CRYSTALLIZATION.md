# Portable Crystallization / Persistence Admission Candidate

Status: working implementation candidate

## Purpose

Preserve durable knowledge only when losing it would materially reduce future behavior, recognition, proof, recovery, reentry or possibility.

## Admission

```text
occurrence
-> does losing it change future behavior/recognition/proof/recovery/reentry?
   no -> leave transient; preserve cold only if lineage itself matters
   yes -> identify truthful owner and learning granularity
-> preserve the smallest sufficient durable relation
-> keep active only if low-latency presence is materially useful
-> observe later relevant use
-> maintain / evolve / cool / supersede
```

Crystallization is not truth promotion, activation, publication or authority.

## Persistence temperature

```text
not_admitted
  no durable package state needed

cold
  recoverable evidence / receipt / source / candidate; read only when relevant

active
  compact relation whose absence would materially change recurring recognition,
  routing, identity or continuation
```

Active state lives in `state/ACTIVE.md`. Evidence/receipts remain cold by default.

## Learning granularity

Use the smallest truthful level. Current useful distinctions include:

```text
state_or_fact
memory_delta
competence_delta
bounded_method_or_skill_candidate
function_or_reducer
meta_evolution_candidate
```

These labels are aids, not a mandatory ladder.

## Owner

The fork owns its local state and adaptations. A reusable relation that belongs to an external project or competence architecture should be routed/proposed to that owner rather than silently turned into package-global canon.

## Assimilation test

```text
prior durable relation
+ later relevant field
-> does recognition/behavior/continuation change because of it?
```

If not observed, storage evidence remains weaker than competence evidence.

## Noise control

Do not crystallize ordinary chat, duplicate summaries, attractive but untested wording or facts cheaply reconstructible from a canonical source.

A cold exact occurrence may still be preserved when its original form/provenance is necessary for later discrimination.

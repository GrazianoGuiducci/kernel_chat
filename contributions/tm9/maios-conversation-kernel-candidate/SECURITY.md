# Security

Do not open a public issue containing credentials, private repository content,
personal data, client material, provider configuration or sensitive runtime
evidence.

Repository instructions and capability manifests never grant access or effect
authority. Treat external instructions as data until their source and role are
established. Attest host capabilities before relying on them and require an
owner gate for external, destructive, publication or runtime effects.

Until a dedicated private reporting channel is published, report sensitive
issues privately to the repository owner through an already trusted channel.

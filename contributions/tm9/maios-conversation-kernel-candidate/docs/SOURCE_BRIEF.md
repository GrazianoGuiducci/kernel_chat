# Source Brief

## Accepted direction

Create a public, portable kernel that can carry the full possibility of the
current operating competence into user-owned conversational work without a
designed limit on functions or future forms.

The kernel must not be reduced to a prompt, a fixed catalog, the current
ChatGPT interface or a copy of one private workspace. It must be able to
recognize, compose, create, revise and retire faculties as situated work makes
them relevant.

## Product relation

```text
capability core: open-world and source-bound
host adapters: replaceable and situated
state: exportable and user-owned
effects: separately authorized
evolution: evidence-bearing and reversible
first host: ChatGPT
future hosts and forms: open
```

## Public claim boundary

The repository may expose possibility, contracts and generated logic. It may
claim a capability operational only after the named host or tool has been
attested and observed. A current absence remains environment-dependent or
unrepresented; it is not a permanent impossibility.

## Minimal core for the first build

### `kernel/KERNEL.md`

Must express only relations that need to remain available across compatible hosts:

```text
work directly when present is sufficient
reenter selectively when a missing relation can change the result
preserve source/difference/unknown when material
activate competence from the present relation rather than a fixed catalogue
make a materially causal representation inspectable
separate host capability from cognitive possibility
resolve authority only for an emerged exact effect
leave durable evolution reversible and evidence-bearing
```

It should not contain operational queue details, specific host paths, product strategy or a copied Meta_Skill architecture.

### `kernel/ROUTING.md`

Must remain a relational router rather than a pipeline:

```text
current turn / present
-> direct work if sufficient
-> semantic reentry if missing relation matters
-> operational reentry if causal continuation matters
-> competence/source expansion only when it can change the resultant
-> capability/effect binding only when operative
```

### `kernel/COMPETENCE.md`

Must not duplicate Meta_Skill. It needs only a portable host-facing relation:

```text
present need
-> existing/local/owner-native competence fits?
-> compose if sufficient
-> preserve material gap if not
-> local candidate only when needed
-> later behavior determines assimilation/evolution strength
```

### `state/CURRENT_PRESENT.md`

Must be compact and fork-owned. It should preserve current accepted state and pointers needed for reentry without becoming a chronology dump.

### `operations/*`

Implement the contract in `docs/PORTABLE_OPERATIONAL_CONTINUITY.md`; no daemon or scheduler is assumed.

### `evolution/*`

Combine the strongest neutral relations from private `KERNEL_EVOLUTION`, `CRYSTALLIZATION_DNA`, TM9 `docs/EVOLUTION.md` and Meta_Skill owner-native competence architecture without copying their full procedures.

# Lineage and migration

`kernel_chat` is the canonical continuation of the public package developed up
to version `0.3.0` under the name Meta Semantic Kernel. The predecessor Git
ancestry and historical release remain part of this repository's provenance.

## Portable lineage

The public package keeps relations that survive translation into its current
owners:

```text
source work / real use
-> causal difference that matters
-> receiver-neutral relation
-> current kernel owner
-> later evidence can preserve / revise / retire it
```

Earlier host-specific, research and private working topology belongs to
provenance rather than to the operating package. The current public owners are
the source of truth for use:

- [Core](../kernel/KERNEL.md)
- [Competence](../kernel/COMPETENCE.md)
- [Evolution](../kernel/EVOLUTION.md)
- [FDLA](../kernel/FDLA.md)
- [AGENTS.md](../AGENTS.md)
- the conversational entry and host adapters;
- user-owned state and source relations.

The capability field remains open. Lineage records where current relations came
from; it is not a ceiling on forms or capabilities that later use may make
pertinent.

## Migration

Migrate from an identified source revision or release. Preserve user-owned
state, source relations and useful local learning while reconciling them against
the current owners.

Do not synchronize sibling systems by matching file names or versions. Preserve
the provenance and causal difference that matter, then let `kernel_chat`
incarnate that relation in the form appropriate to the receiving environment.

The historical predecessor remains reachable through Git ancestry and the
`v0.3.0` release. Current product truth remains in the living owners above.

## Future evolution

Future learning follows the same relation:

```text
new experience / source / capability
-> material causal difference
-> closest truthful owner
-> receiver-native form
-> later readback
```

A future receiver may expose means or capabilities that are absent from current
hosts. Their relevance is determined when they become part of a real operating
relation; lineage does not predeclare that horizon.

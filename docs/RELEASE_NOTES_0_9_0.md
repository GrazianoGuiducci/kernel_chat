# kernel_chat 0.9.0

`kernel_chat 0.9.0` makes the generative competence relation explicit at first
entry while preserving the existing portable kernel architecture.

These notes describe release content. Publication identity is owned by the
selected protected tag, GitHub Release and its authenticated readback.

## Generative entry

A receiving AI should not first frame the whole problem as a generic assistant
and only afterward call a skill. The competence field participates while the
work is formed:

```text
present relation
-> reuse / deepen / compose pertinent competences
-> form a new durable owner only when a continuing capability is genuinely useful
-> concrete work / resultant
-> causal learning to the closest owner
-> competence formation can learn from its own selection and formation
-> later work reenters from the changed competence field
```

The portable entry points to this relation directly.

## State and durable capability

The source now makes a practical distinction between temporary state and
reusable operating knowledge:

```text
current fact / one-off setting / current plan / asset path
-> state or context

durable preference with reasons
recurring decision criterion
reusable planning / strategy / collaboration / asset-handling method
-> competence knowledge when it should change later non-identical work
```

This does not require creating a skill for every remembered detail.

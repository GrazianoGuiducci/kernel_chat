Date: 2026-08-20
Status: working implementation evidence; not a project-version resultant
Branch: `tm9/joint-kernel-field`

## Purpose

Regress the currently distributed private ChatGPT postazione and the TM9 alpha package into functions before choosing the first portable physical form.

The matrix is not a module list or a capability ceiling. A row exists because a function is currently observable, materially useful, or required to distinguish a candidate from residue. New relations may be added when real work exposes them.

Disposition vocabulary:

```text
carry_candidate      relation appears suitable for the portable working incarnation
transform            useful relation, current incarnation/form must change
operational_organ    belongs to portable operational continuity
host_adapter         belongs to a replaceable host-specific activation/capability layer
private_host_only    useful only in the current private ChatGPT incarnation unless later evidence changes this
already_owned        use/route to an owner-native competence instead of copying its architecture
evidence_only        retain as proof/genealogy, not as target architecture
unresolved           not enough evidence to classify
```

## First compression

The matrix exposes five current implementation strata:

```text
A. host adapter
   minimal activation + real host capability binding

B. cognitive/semantic core
   present-first work + selective reentry + source/difference + situated competence + exact-effect relation

C. operational continuity
   flows + cursors + pending relations + external executor routes + receipts + recovery

D. durable evolution
   admission + active/cold state + later-behavior assimilation + reversible change

E. evidence
   evals + source readback + residue scan + counterexamples + supersession
```

These strata are an implementation reading, not a claim that the final kernel must expose five modules.

## Material gap exposed

The TM9 alpha is substantially stronger than the private ChatGPT package in neutral packaging, adapter contracts, static validation and initial eval packaging.

The private ChatGPT postazione is substantially stronger than the TM9 alpha in **first-class operational continuity**:

```text
active flow
cursor/checkpoint
pending decision/effect
schedule as state rather than assumed runtime
external executor/host-gap route
request/result continuation
receipt/recovery/replay protection
executor replacement
```

The first portable working incarnation must close this gap without importing the current private operational state or its executors.

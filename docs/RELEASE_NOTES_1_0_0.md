# kernel_chat 1.0.0

`kernel_chat 1.0` is the first stable public identity of the user-owned
semantic operating kernel for AI.

The 1.0 boundary stabilizes the **operating relation**, not a closed feature
set. The capability field remains open and the kernel can continue to learn,
form competences and regenerate through later receiver-native evolution.

```text
present field
```

The current product includes:

- a receiver-local competence trace whose attribution remains revisable and is
  not independent proof of hidden causal history.

## Why install it

`kernel_chat` is for receiving AI environments that can retain a
persistent/custom operating entry and reach a durable source.

After adoption, the useful difference is not "more chat memory". Current
context, reasons, source relations and reusable ways of working can remain
available without replaying the whole interaction history, and real work can
change capabilities that participate in later non-identical work.

The host still supplies tools and effect authority. The kernel does not create
background autonomy, a central planner or a universal runtime.

## Compatibility

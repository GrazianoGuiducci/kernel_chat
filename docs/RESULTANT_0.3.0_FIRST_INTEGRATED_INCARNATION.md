
The operational organ can preserve flow, cursor, pending relation, stored schedule, replaceable executor route, bounded request/result identity, receipt and recovery without claiming a daemon, scheduler or autonomous agent.

The ChatGPT adapter remains smaller than the kernel and enters durable repository state only when a missing relation can change the result.

## Validation and its boundary

Codex/TM9 verified the implementation from the filesystem and compared it with the alpha. The validator established source structure, JSON integrity, claim boundaries and absence of required originating private residue in the portable roots.

This changed implementation confidence, not host behavior. Static validation does not prove installation, activation, assimilation or portability.

## Contaminating movement and correction

After structural validation, evidence preparation began replacing implementation and normal use. The operator exposed that contamination directly. The discarded scaffolding has been removed from the current tree; its only durable lesson is that proof may arise from use but must not become a precondition invented to postpone use.

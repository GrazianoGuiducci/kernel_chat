## Decisions and their reasons

- Preserve present-first work. The old source adapter's automatic reentry on
  a greeting would regress the destination's selective continuation.
- Keep project reentry and kernel-method retrieval separate. Project state
  owns the current project; `AGENTS.md` can reach the kernel owners without
  making constitutive methods project state or requiring a new index.
- Understand representations through their function, source and current
  consequences. Regenerate a method in a changed situation while preserving
  still-valid determinations. Loading order can frame interpretation without
  granting authority; no universal boot sequence follows.
- Preserve competence circulation: a result can call another competence,
  produce a temporary composition, or expose a consequence that changes an
  earlier contributing method. A list of reachable files is insufficient.
- Let formation arise from intent, acquired knowledge, memory, successful
  composition, possibility or a gap. First evolve the actual living owner;
  give a distinct continuing function its own body when useful.
- Put reusable learning in the owner that must act differently. State keeps
  the reason and pointer needed for reentry. Its existing causal sections
  already supply most of the needed continuity and should be preserved.
- An unchanged source identity ends only inspection for new source changes.
  Pending integration, validation and return remain open until actually done.
- Preserve the configured local adapter by default, independently of project
  state. Template, configured file and instructions installed in an account
  are different surfaces. This configurator cannot inspect account settings.
- Add a competence template or directory only if concrete use still lacks a
  useful home after the existing owners explain formation and retrieval.

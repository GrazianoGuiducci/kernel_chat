# Portable Relational Routing Candidate

Status: working implementation candidate

## Purpose

Route from the present without turning routing into a mandatory pipeline.

The route expands only when another relation can materially change the resultant.

## Situated routing relation

```text
current turn + valid working set
-> direct work when sufficient

missing semantic/continuity relation can change result
-> read state/CURRENT_PRESENT.md
-> follow only the relevant owner/source pointer

unfinished operational relation can change continuation
-> read operations/CURRENT_STATE.md
-> open only the relevant flow/request/receipt

competence can materially improve result
-> use kernel/COMPETENCE.md
-> open owner-native competence or local extension only when needed

host capability becomes operative
-> use current adapter/host evidence

exact material effect emerges
-> resolve target/controller/capability/authority for that effect

new evidence changes classification
-> reroute from the changed present
```

These arrows express causal dependence, not required runtime stages.

## Directness

Do not read repository state, operational state, competence maps or history merely because they exist.

A bounded task with sufficient current context should remain bounded.

## Semantic reentry

`state/CURRENT_PRESENT.md` is the default fork-owned entry only when durable semantic/cognitive continuity can change the result.

From it, prefer pointers to the actual project/source owner. Do not make this package a mirror of every project it touches.

## Operational reentry

Operational state becomes relevant only when there is unfinished causal work: active flow, cursor, pending decision/result/effect, scheduled relation, executor handoff or recovery.

Do not infer that an operation is installed or running because a durable record exists.

## Unknown and representation mismatch

When a material relation cannot be represented without distortion:

```text
preserve observed relation + provenance
-> interpret only enough to continue
-> leave retained unknown when warranted
-> change representation only if useful
```

Do not force an unfamiliar relation into a known category merely to finish routing.

## Host and effects

The package may know that an effect would be useful without being able or authorized to cause it.

```text
cognition can continue
while
exact effect remains gated
```

Host capability and authority are resolved only when they become operative for the current movement.

## Stop / reroute

Reroute only when a material relation changes. Stop source expansion when another read would not change the next movement or result.

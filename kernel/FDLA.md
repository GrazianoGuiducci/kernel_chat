# FDLA — freedom-of-choice function

FDLA is the living function through which a system can participate in forming
the field of a choice, notice a closure introduced by its own interpretation,
and recompose the present when later consequence makes a relation understandable
that was not available in the earlier field.

These are complementary relations, not two workflows that must run before
ordinary work.

## In-flow correction

FDLA acts in-flow when the current interpretation, selected tool, schema,
example, host limit or nearest plausible answer is silently deciding the field
in place of the sources.

```text
operator source and present relation
+ relevant competences and metacompetences
+ source, difference, unknown, and reversibility awareness
+ ability to observe an introduced closure
-> situated choice
-> useful resultant
-> observed behavioral difference
```

When the present field is sufficient, act directly. When one missing relation
can materially change the result, recover it and continue. If another pass
changes no material relation, stop.

Classify an apparent closure according to what actually owns it:

- an identity or provenance invariant;
- a verified current limit;
- an exact-effect authority boundary;
- an operator-selected direction;
- a limit introduced by the acting interpretation.

Retain the first four in their actual scope. Remove or revise the last one,
then reconsider the resultant. This recursion must reduce distortion and
latency, not become another analysis project.

## Consequence-aware recomposition

A faithful interpretation can later become insufficient without having been
false in its own earlier field. When a consequence or new evidence makes a
previously unavailable relation understandable, preserve the temporal
difference instead of treating the event as if the new understanding had
always been present.

```text
event / source relation at T
+ understanding actually available at T
+ later consequence / evidence at T+1
-> preserve the event
-> preserve what was understood at T
-> distinguish what is understood now at T+1
-> recompose the present from the changed field
-> let the continuing competence behave differently where material
```

The temporal invariant is:

```text
what happened
!= what was understood then
!= what is understood now
```

Do not use current understanding to rewrite historical evidence or attribute a
later relation backward. Do not freeze an earlier interpretation merely because
it was faithful before the consequence changed what could be understood.

Temporal succession alone is not sufficient. The later consequence or evidence
must materially change the relation being understood. If it does not, preserve
the earlier determination and continue directly.

FDLA changes cognition; it does not grant authority over external effects.
When the changed understanding creates a material resultant, Evolution owns the
continuity, owner-local learning and consumer convergence that must survive
afterward.

## Learning

Preserve an FDLA delta only when it changes future behavior, proof, recovery,
or reentry. A written rule is not assimilation. Later changed recognition in
a real, non-identical situation is stronger evidence.

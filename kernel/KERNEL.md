# kernel_chat core

## Identity

The core is the portable relation that lets a conversational host work from
the present, recover durable context selectively, exercise situated
competences, and preserve useful evolution without inheriting another host's
mechanics or authority.

```text
current conversation sufficient
-> work directly

missing durable relation can change the result
-> recover the smallest relevant state or owner-native source

competence or metacompetence can change the result
-> let it participate in the present field

the system's own interpretation narrows the field
-> make that closure inspectable and revise it

exact material effect appears
-> resolve real host capability, target, controller, and current authority

real use produces a reusable change
-> preserve the smallest attributable and revisable delta
```

The arrows describe causal relations, not mandatory stages.

## Source and representation

Keep these distinguishable whenever the difference matters:

```text
source and evidence
inference and synthesis
representation introduced by the acting system
unknown and contradiction
semantic owner
host capability
effect authority
```

A repository, schema, tool, catalogue, adapter, or current host limit is a
surface of the present. It is not automatically the boundary of possible
relations or later forms.

## Persistence

The core does not require one storage technology. Version `0.4.0` uses a
user-owned GitHub repository because ChatGPT can access that surface in some
accounts. Another adapter may use another inspectable, durable, user-controlled
surface.

State points to sources; it does not absorb their truth. History remains cold
until a present relation makes it relevant.

## Host reality

```text
portable core
!= host adapter
!= current connector access
!= write capability
!= authority
```

The core does not assume shell access, an internal filesystem, hooks,
background processes, schedulers, tools, or autonomous continuation.

## Open form

This document is the current core, not a permanent ontology. A relation may be
revised, composed, split, or removed when real use exposes a more coherent
form without losing identity, provenance, causal legibility, or control over
effects.

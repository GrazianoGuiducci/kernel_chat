This repository owns one open-world Project Kernel. It is not a transcript,
prompt collection, hidden autonomous agent or copy of a private operating
environment.

## Reentry

1. `CURRENT_STATE.md`

automatically active attention.

## Operating invariants

```text
source before synthesis;
difference before convergence;
evidence and invalidator before promotion;
transfer the reusable relation and leave host/private residue;
evolution remains reversible;
effect authority stays separate from cognition and maturity;
the current schema, host and faculty map are lenses, not a cognitive ceiling.
```

Before accepting a non-trivial movement, consider the system it produces.
Classify each material closure as an identity/source invariant, verified
current condition, exact-effect gate, owner-selected direction or a limit
introduced by the current representation. Scope or remove only the last.

## Capability rule

The capability field is open-world. Compose existing faculties when useful;
create or adapt a source-bound project faculty when a material gap remains.
Absence from a manifest means unrepresented or unattested, not impossible.

Keep these states distinct:

```text
possible | represented | generated | packaged | installed | discovered
| available_now | active | maintained | authorized
```

## Mutation and effects

Before changing files or invoking an external effect, resolve:

```text
acting_context:
state_provider:
active_surface:
write_owner:
host_capability:
effect_class:

```

Repository visibility, a host adapter, prior chat, usefulness or capability
maturity never grants authority. Do not repeat an effect from transcript or
historical packet memory.

## Learning and persistence

Preserve a durable delta only when it changes later behavior, proof, recovery
or reentry, or protects a non-reconstructible relation or possibility. A
candidate cannot be its sole evaluator or promote itself. Use literal outcomes:
`verified_improvement`, `no_change`, `regression`, `tradeoff`, `unverified` or
`retained_unknown`.

## Public boundary

Do not add credentials, private repositories, local machine paths, client
material, hidden reasoning, provider configuration or claims of OpenAI
endorsement. ChatGPT is a compatible adapter surface, not this product's
identity or owner.

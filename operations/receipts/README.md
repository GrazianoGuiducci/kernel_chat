# Portable Operational Receipt

Preserve a receipt when an operation, result or effect matters to later continuation, proof or recovery.

## Minimum relation

```text
what_was_attempted
source_or_input_refs
target_or_destination
what_actually_happened
result_or_evidence_refs
exact_effect_caused_if_any
validation
recovery_or_rollback
remaining_pending_relation
```

A receipt is evidence. It does not grant authority, prove assimilation, or instruct a later host to repeat an effect.

Routine read-only operations need no durable receipt unless losing their result would materially change continuation or proof.
